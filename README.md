# python-visualization
Python Visualization Project

A comparative analysis of five Python visualization libraries using Canadian CPI data (2002–2024). This project explores how Matplotlib, Seaborn, Bokeh, Altair, and Plotly can be used to visualize inflation trends across key CPI categories such as All-items, Food, and Shelter. It highlights differences in functionality, interactivity, and ease of use across libraries while demonstrating effective data preparation and storytelling with real economic data.

Setup: Install required libraries using pip install pandas matplotlib seaborn bokeh altair plotly and run in Google Colab with Google Drive mounted. The dataset is sourced from Statistics Canada CPI indices (2002–2024).
